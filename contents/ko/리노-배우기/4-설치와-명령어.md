# 설치와 명령어

## 설치

최신 Node.js를 설치한 뒤 스타터 프로젝트를 생성합니다.

```bash
npm create rino@latest
```

기존 ESM 프로젝트에 직접 추가하려면 다음 명령을 사용합니다.

```bash
npm install rinojs
```

`package.json`에는 `"type": "module"`과 다음과 같은 스크립트가 필요합니다.

```json
{
  "type": "module",
  "scripts": {
    "dev": "node dev.js",
    "generate": "node generate.js",
    "generate-all": "node generate.js && node sitemap.js && node feed.js",
    "generate-sitemap": "node generate.js && node sitemap.js",
    "sitemap": "node sitemap.js",
    "feed": "node feed.js",
    "backoffice": "node backoffice.js"
  },
  "dependencies": { "rinojs": "^3.0.0" }
}
```

## 명령어

- 개발 서버: `npm run dev`
- 웹사이트 빌드: `npm run generate`
- 웹사이트와 사이트맵 빌드: `npm run generate-sitemap`
- 웹사이트, 사이트맵, 피드 빌드: `npm run generate-all`
- 사이트맵만 빌드: `npm run sitemap`
- RSS와 Atom 피드만 빌드: `npm run feed`
- 백오피스 서버: `npm run backoffice`

개발 서버는 결과를 메모리에 빌드하고 프로젝트 파일을 감시합니다. 정적 빌드는 기본적으로 `dist`에 기록하며, `rino-config.js`의 `dist`로 경로를 바꿀 수 있습니다.
